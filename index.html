試作：冒険・マージの盤・打ち分け
支度
道 ◆

    段1 マージの盤

    段2 打ち分け

    地域1のボスを倒すと開く。装備作りの出口に入れた素材で、武器・防具・アクセサリーを打つ。

    出口

    毎分　拾う 0　合わせた 0　あふれ 0

    記録（試すとき用）

    版

    遊び方

    • 勇者は止まらず道を進み、敵と自動で戦う。倒した敵の落とし物が盤に出る。
    • 物を同じ物（同じ種類・同じランク）の上に重ねると合わさる。重ねた物と、重ねた先につながった同じ物を合わせて3個なら上のランク1個、5個なら上のランク2個。ランクが1つ上がると価値は3倍。3個は損得なしで場所が空き、5個は2割の得。
    • 物はドラッグで動かす（押してから動かす先を押してもよい）。空きマスに置くと動くだけで、隣に並べても合わさらない。違う物の上に置くと入れ替わる。拾っただけでも合わさらない。
    • 盤の物を出口へ入れる：支度（冒険を続けられる時間が伸びる）、育てる（経験。レベル1つで攻撃と HP が8%伸びる）、装備作り（打ち分けの素材と燃料）、工房（盤を広げる・職人を鍛える。地域1のボスの後に開く）。
    • 出発のときの支度は30秒ぶん。支度が切れるか倒れると村へ帰り、3秒待って入口から出発し直す。倒れたときは支度の残りを失う。
    • 盤がいっぱいのときに拾った物は、そのまま支度に入る（あふれ）。損をしている印。
    • 道の終わり（◆）のボスを倒すのが目標。画面を閉じている間や裏のタブの間は止まる。

    段2 打ち分け（地域1のボスの後）

    • 素材で作れる物が決まる：鉄鉱・銅鉱からは武器と防具、炎・石の欠片からはアクセサリー。格n を打つと素材を 30×3^(n−1) 使う（格1は30、格2は90）。
    • 同じ物で格が同じか下を打つと、数値が加算される（格ごとに4回まで）。格が上を打つと、加算を全部引き継いで格上げ。
    • 燃料に欠片を入れる。入れた価値の合計が集中力（叩くたびに減る）。炎の欠片は価値3ごとに「火を足す」が1回使える。
    • 叩き方を選んでマスを押す。叩く前に伸びが見える（マウスなら重ねるだけ、タッチなら1回目で見えて2回目で叩く）。各マスの目標の帯に入れば○、真ん中で◎、超えるとひび。全部◎なら会心。
    • 温度は 灼熱（伸び2倍）→ 赤熱 → 暗赤（半分）。決まった回数叩くと下がる。「火を足す」は段の頭で1段戻す。冷えるか集中力が切れると仕上がる。「仕上げる」でいつでも止められる。
    • 出来は基本の50〜100%（会心は120%）。武器は攻撃、鎧は HP、盾は1回に受けるダメージを引く。アクセサリーは持っている物が全部効く。
    • 地域2のボスの後はマージの職人が盤を合わせ、地域3のボスの後は打ち分けの職人が、手で出した一番の手順で打ち続ける。
