試作：冒険・マージの盤・打ち分け・道場
支度
道 ◆

    段1 マージの盤

    段2 打ち分け

    地域1のボスを倒すと開く。装備作りの出口に入れた素材で、武器・防具・アクセサリーを打つ。

    段3 道場

    地域2のボスを倒すと開く。巻物を解いてスキルツリーの節を上げる。

    出口

    毎分　拾う 0　合わせた 0　あふれ 0

    記録（試すとき用）

    版

    遊び方

    • 勇者は止まらず道を進み、敵と自動で戦う。倒した敵の落とし物が盤に出る。
    • 物を同じ物（同じ種類・同じランク）の上に重ねると合わさる。重ねた物と、重ねた先につながった同じ物を合わせて3個なら上のランク1個、5個なら上のランク2個。ランクが1つ上がると価値は3倍。3個は損得なしで場所が空き、5個は2割の得。
    • 物はドラッグで動かす（押してから動かす先を押してもよい）。空きマスに置くと動くだけで、隣に並べても合わさらない。違う物の上に置くと入れ替わる。拾っただけでも合わさらない。
    • 盤の物を出口へ入れる：支度（冒険を続けられる時間が伸びる）、育てる（経験。レベル1つで攻撃と HP が8%伸びる）、装備作り（打ち分けの素材と燃料）、工房（盤を広げる・職人を鍛える。地域1のボスの後に開く）。
    • 勇者は1秒に20歩進む。出発のときの支度は30秒ぶん。支度が切れるか倒れると村へ帰り、3秒待って入口から出発し直す。倒れたときは支度の残りを失う。
    • 盤がいっぱいのときに拾った物は、そのまま支度に入る（あふれ）。損をしている印。
    • 道の終わり（◆）のボスを倒すのが目標。画面を閉じている間や裏のタブの間は止まる。

    段3 道場（地域2のボスの後）

    • 守りの流派のスキルツリーの節を選び、巻物を開く。数字は、まわり8マス（十字の巻物は上下左右に2マスずつ）の罠の数。罠でないマスを全部開ければ解けた。どの巻物も当てずっぽうなしに推理だけで解ける。
    • 解くと熟練3（ミス1回につき −1、最低1）。熟練2で節が1段上がる（5段まで）。節が 1/5 になると次の節が開く。
    • 小さい節は段ごとに HP や攻撃が伸びる。技の節を上げると、その技を巻物で「修行中の技」として使える（戦いでの効きは次の工程）。
    • 変えルール：十字（数える形が十字）、連結（罠は全部つながる）、組（罠は2つずつの組で、組どうし接しない）。

    技の並び（道場の中）

    • 戦いでは普通の攻撃の合間に、並べた札を左から順に使う。最後の札の後は積み直し（武器の秒数）で、その間も普通の攻撃。並びが空なら普通の攻撃だけ。
    • 札の時間は「振り」（武器の攻撃1回ぶん）。修飾（溜め）はたまって次の技に掛かり、頭に戻っても消えない。条件（傷の構え）は合わなければ次の1枚を飛ばす。
    • 枠は3つから。技・札の節が 3/5 になるたびに1つ増える（最大10）。札の効きは節の段ごとに ＋10%。並びは地域ごとに決め、まだない地域は一つ前の地域の並びを使う。
    • 敵の性質：古い森は殻（1回の攻撃から引く。大きい一撃や崩しが効く）、雪山は盾（最初の数回を防ぐ）、沼地は回復。木人で、並びなしと比べた強さが分かる。

    段2 打ち分け（地域1のボスの後）

    • 素材で作れる物が決まる：鉄鉱・銅鉱からは武器と防具、炎・石の欠片からはアクセサリー。格n を打つと素材を 30×3^(n−1) 使う（格1は30、格2は90）。
    • 同じ物で格が同じか下を打つと、数値が加算される（格ごとに4回まで）。格が上を打つと、加算を全部引き継いで格上げ。
    • 燃料に欠片を入れる。入れた価値の合計が集中力（叩くたびに減る）。炎の欠片は価値3ごとに「火を足す」が1回使える。
    • 叩き方を選んでマスを押す。叩く前に伸びが見える（マウスなら重ねるだけ、タッチなら1回目で見えて2回目で叩く）。各マスの目標の帯に入れば○、真ん中で◎、超えるとひび。全部◎なら会心。
    • 温度は 灼熱（伸び2倍）→ 赤熱 → 暗赤（半分）。1段で叩ける回数（鉄は3回、銅は4回）を叩くと下がる。残りの回数は丸（●叩いた・○残り）で見える。「火を足す」はいつでも使え、1段熱くなってその段を最初から叩ける。冷えるか集中力が切れると仕上がる。「仕上げる」でいつでも止められる。
    • 出来は基本の50〜100%（会心は120%）。武器は攻撃、鎧は HP、盾は1回に受けるダメージを引く。アクセサリーは持っている物が全部効く。
    • 地域2のボスの後はマージの職人が盤を合わせ、地域3のボスの後は打ち分けの職人が、手で出した一番の手順で打ち続ける。
