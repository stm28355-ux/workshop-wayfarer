## ボットの決まりごと（判定表 第11回 D2）

- 手は1つ。盤の1手は3秒、打ち分けは3秒＋1手1.5秒（解く道具の一番の手順。火を足す手は使わない）、巻物は1枚60秒（ミスなし）。手がふさがっている間は盤に触らない。
- 盤：5個になる手はすぐ、空きが6マス以下なら3個でも合わせる。ランク3以上か、空きが3マス以下なら一番低い物を配る。
- 配り方：今の支度がボスまで（倒れ続けているときは届いた所まで）に足りなければ支度。足りていれば 地域1は育てる9割・装備1割、地域2からは 育てる42%・装備50%・工房8%。
- 打ち分け：鉄の剣・銅の盾・銅の槌・炎の腕輪・石の護符を順に、格上げか加算。集中力16（欠片が12以上あるとき）。毎秒の攻撃が大きい方の武器を持つ。
- 道場：構え・返しの型・盾打ち…の順に節を上げ、並びは 溜め → 強斬り → 盾打ち を枠の数まで。巻物は手の時間の4割まで。
