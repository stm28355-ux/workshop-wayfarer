# 工程9 通しの釣り合い（Issue #25）

2026-11-29。人が遊んで確かめる回は増やさず、道具で決めた（判定表 第18回の一言「テストだけで日が暮れる」）。

## 道具

- `tools/run-through.mjs`：地域1〜3 の通し（前から）。
- `tools/region-time.mjs`（新しい）：地域4〜6 の「入ってからボスを初めて倒すまで」。
  - 予定表どおりの「地域3を出るとき」の勇者で雪山に入り、`CHAIN=1` で魔王まで続けて回す。
  - 盤は通しのボットと同じ手。装備作りと巻物は答えを解かず、決まった手の時間（装備 20〜50秒、巻物 90秒）で会心・ミスなしにしたことにする。人より速い上の見積もり。
  - 装備は「強さ（毎秒の攻撃 × √もつ回数）が一番伸びる物」を打てる一番上の格で打ち、持ち替えと技の並びはボスと試しに戦って決める。
  - `SET=4.boss.hp:5500,5.boss.hp:30000` のように数値をその回だけ変えて試せる。
- `tools/profiles.mjs`：予定表どおりの勇者（地域3〜6を出るとき）。`r4-sim.mjs` と共有。

## 決めたこと

- 雪山のボス HP 7000 → 5500、沼地のボス HP 16000 → 30000。
- 雪山のボス 4500〜6000 の間では、ボットの時間は 59〜76分でばらつく。手の選び方でも ±20分動くので、細かい数字より形（どの地域も40〜80分、どこも極端に長くない）で決めた。
- 予定の勇者でのボス戦（`r4-sim.mjs` DUEL=1）：
  - 沼地・魔王の城は「入るときは負け、出るときは並びありで勝ち、並びなしで負け」のまま。
  - 雪山は 5500 にすると、出るときの勇者が並びなしでも勝つ（49秒）。ボットの勇者は予定より弱く（レベル12・防具 格2）、並びが要った。雪山の壁は道の盾の兵と、ボスを速く倒す所に残る。
- 地域1〜3 はボットだと予定より速いが、直さない。ボットは手の時間だけで考える時間がなく、人の記録（第12回）はボットより遅かった。人だと予定に近くなる見込み。全体（約4時間20分）は予定（4時間24分）とそろっている。
