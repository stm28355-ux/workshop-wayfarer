## 作るときの決めごと

- ルールの心臓部（冒険・マージ・職人・打ち分け・技の並び・解読の判定）は「状態＋経った時間（または手）→ 新しい状態」の純粋な関数にする（`src/core/`）。画面（`src/ui/`）はそれを呼ぶだけ。
- 乱数は入れない。敵の落とし物も決まっている。巻物の生成だけ種つき（同じ種なら同じ問題）。
- 数値はデータの表に分け、人が見て直せる形にする（`src/data/`）。
- 道具（測る・問題を作る）は `tools/` に置き、ゲームには出さない。報告では「ゲームに出る物か、道具だけか」を言う。
- 版は `package.json` と `src/version.js` をそろえる（テストで確かめる）。
- 保存は localStorage（版つき）。試すときは `?test=open`（全部開く）と `?speed=`（早送り）。
- 画面や言葉を変えたら、コミットの前に全ページを開く。遊び方とことばの一覧も同じコミットで直す。
- コミットは自分のファイルを名前で足す（`git add -A` は使わない）。試しのまとめや設定はリポジトリの外（scratchpad か Claude Docs）に置く。
- 「忘れないようにメモ」は Issue にし、工程のマイルストーンを付ける。工程を閉じる前に残りの Issue を並べる。
- 人が遊ぶのは工程ごとに1回、1回20分まで。判定表で答えてもらう。

## 工程0（2026-11-27）

- `src/core/rank.js`：マージのランク（1〜7）と価値（ランクごとに3倍、ランク7＝729）、3個→1個・5個→2個、合わせる前後の価値の比。
- `index.html`：ランクと価値の見本だけ。工程2で冒険とマージの画面に置き換える。
- 手元で開く設定は ClaudeCode/.claude/launch.json の "workshop-wayfarer"（ポート 5194）。

## 工程1（2026-11-27）

- `src/data/balance.js`：冒険とマージの仮の数値。1刻み＝0.1秒、歩く速さは1刻みに1歩。地域6つ（名前・壁・敵・ボス・落とし物・ボスで開く物）、勇者、経験、支度、盤、出口、物の種類。
- `src/core/board.js`：マージの盤。拾った物は左上から読む順の空きに置き、勝手には合わせない。手で動かした先で同じ物が3個以上つながれば合わせる（5個以上なら5個→2個、3〜4個なら3個→1個）。物の上に動かすと入れ替わる。
- `src/core/hero.js`：レベル（攻撃・最大HP）と経験（次に要る量は1.6倍ずつ）。
- `src/core/game.js`：`advance(状態, 刻み)` で冒険を進める。支度は毎刻み減り、切れたら帰ってすぐ出発。敵は決まった歩ごとに出て、倒すと決まった物を落とす。攻撃は1秒に1回、歩いている間だけ回復。倒れたら支度の残りを失って帰る。盤がいっぱいなら拾った物は支度に入る（あふれ）。ボスを倒すと開く物を開いて帰る。人の手は `moveItem`・`feed`（出口：支度・育てる・装備作り・工房）・`chooseRegion`。
- テスト35個。同じ状態から同じだけ進めれば同じ結果、分けて進めても同じ、を確かめた。`test/pace.test.js` は C1（手を出さないと1分ほどであふれる）を守る。
- `tools/measure-run.mjs`（道具だけ）：遊び方を5つ決めて地域1を回す。結果は [docs/measure/phase1.md](measure/phase1.md)。
- 仮の数値の前提：地域1のボスは「合わせて配る」ボット（1秒に1手）で23分ほど。人はボットより上手なので、工程2で遊んでもらって直す。
- 決めごとを1つ足した：拾った物が盤に出ても勝手には合わせない（5個そろうまで待つかは人が選ぶ）。

## 工程2（2026-11-27）試作画面

- `index.html`・`src/ui/main.js`・`style.css`：上に冒険の帯（地域・勇者のレベルと HP・支度・道とボス・戦っている敵・ログ4行）、下に段1 マージの盤（5×4）と出口4つ・毎分の数3つ（拾う・合わせた・あふれ）。
- 操作：物をドラッグして別のマスや出口へ。押して選んでから動かす先や出口を押してもよい（キーボードは Enter）。選ぶと出口ごとに増える量（支度＋◯秒、育てる＋◯経験）が出る。
- 保存は localStorage（`src/ui/save.js`、5秒ごとと閉じるとき）。閉じている間・裏のタブの間は止まる（C4）。コマが間引かれても1秒までは追いつく。
- 試すとき：`?speed=4`（4倍速、0.25〜20）、`?test=open`（全部の地域と工房の出口が開く）。`window.describeUI()` で画面のまとめを読める。
- スマホ（375px）：帯を詰め、出口を盤の下に4つ横並びにして、帯・盤・出口が1画面に入る（マス 63px）。
- 物の見た目は仮（色つきの四角に漢字1字とランクの数字）。絵は工程8。
- あふれのログは続いている間1行にまとめる（毎回出すとほかのことが流れて見えなくなった）。

## 工程2 の直し（2026-11-27、0.3.1）判定表 第2回

- 判定：Q1 直す、Q2〜Q10 OK（次は工程3）。一言：Q3「素材が増えたとき盤が足りるかは微妙だが、捨てる所を考えるので問題なさそう」、Q4「序盤だけ弱いので、素材を稼ぐ速さを考えると支度をサボる選択肢がある（問題にはしない）」、Q9「合わせた数はあまり見ていない」。人の記録：20分くらい、レベル8。あとで画面の記録で確かめた値：遊んだ時間20分・倒れて帰った2回・支度が切れて帰った7回（ボットは倒れ7〜8回・支度切れ0〜1回で逆。人は育てるに多く入れて倒れにくく、支度は使い切る）。
- Q1「並べただけで合わさって困惑。操作ミスが起こりやすい。いくつかくっついている所に重ねたときに合わさるのが正しい」→ 合わせ方を変えた（`src/core/board.js` の `move`）：空きマスに置くと動くだけ。同じ物の上に重ねると、重ねた物＋重ねた先につながった同じ物で3個以上なら合わさる（5個以上なら2個）。1個だけの所に重ねても何も起きず、画面に「重ねて3個以上にならないと合わさらない」。違う物の上なら入れ替わるだけ。
- 記録（「テスト用に今は残してほしい」）：`stats.firstBoss[地域] = { tick, level }` を残し、画面の出口の下に「記録（試すとき用）」：遊んだ時間・出発・倒れて帰った・支度が切れて帰った・ボスを初めて倒した時間とレベル。
- 測り直し（`node tools/measure-run.mjs 25`）：合わせて配るボットは1秒に1手で1349秒（22分）、3秒に1手で1471秒、どちらもレベル7。重ねて合わせる形になってボットが合わせる回数は減ったが、ボスまでの時間はほぼ同じ。
